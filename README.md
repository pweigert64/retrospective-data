# 🏔️ Retrospective Data

This repository is the centralized asset storage for the **Alpine Retrospective** project. It contains high-resolution photography and GPS tracks from over lots of years of mountaineering and cycling across Austria.

### 📁 Contents
* **GPX Tracks:** Precise GPS data for hiking, climbing, and cycling tours.
* **WebP Images:** Optimized photography of the Totes Gebirge, Gesäuse, and Dachstein regions.
